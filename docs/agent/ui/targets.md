Only the running instance's main window is a command owner in this release. Use instances/windows/context to discover it. A session workspace belongs to an ORG2 local session, not a browser or PTY session. --session and --global are mutually exclusive. Raw mutations require an explicit workspace or host-bound target file; context may inspect the current presentation. Concrete native tools default to the calling session, and CLI calls can use ORG2_UI_TARGET_FILE. Neither adapter infers a write destination from the visible session.

Relative file paths resolve against the target repository, not the CLI working directory. Global workspace relative paths use the selected app repository. Files are canonicalized and checked for readable regular-file access before a tab is created. Exact absolute paths can open artifacts outside the repository under the authenticated local user's authority. No file contents are returned to the caller.

--reveal requests MyStation navigation and selection. It does not request OS window focus and does not wait for the renderer. Results report presentationState=requested and revealed=false until a rendered acknowledgement is supported. Line positions remain pending in the tab and are applied when the editor mounts. Browser creation is limited to the currently presented workspace to preserve the existing BrowserContext synchronization owner.

All endpoints require an instance-specific local credential; browser-origin requests are rejected. UI reads are available to authenticated callers, while UI mutations require the existing ADE Manager setting. The same policy runs for the built-in harness and CLI. A caller-supplied target session is never used as sender identity.

The CLI reads endpoints only beneath the selected ORGII_HOME. It does not poll, start a desktop app, create an agent session, or modify harness configuration. Its instance handshake rejects stale descriptors and mismatched catalogs. Do not copy endpoint credentials into a prompt or command argument.
