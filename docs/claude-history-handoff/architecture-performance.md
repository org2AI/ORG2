# Automatic handoff architecture and performance review

Evidence labels: **static** means source inspection; **fixture** means an isolated automated test; **native pending** means the real application scenario has not been accepted.

## Architecture: ten-layer review

| Layer                     | Scope and conclusion                                                                                                                                                                                          | Evidence / remaining work                                                                                                                                                                                   |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1 Compilation             | Owner API and native implementation compile; the synchronization UI, schema and IPC are removed.                                                                                                              | Final lifecycle source passed strict Clippy and 90 native Market tests; handoff tests passed 42 cases with 5 opt-in fixtures ignored. The final combined macOS App build passed with the lifecycle changes. |
| 2 Dead code / duplication | Manual frontend list/select/inspect/sync controls and translation keys removed. Writer classification is shared by the safety check and exit subscription.                                                    | Static; native compiler remains the final unused-code check.                                                                                                                                                |
| 3 Naming                  | The existing connection description explains automatic handoff; native diagnostics distinguish pending, busy, clean and attention. Provider/configuration ownership is not renamed as conversation ownership. | Static.                                                                                                                                                                                                     |
| 4 Semantic overloading    | A process-exit event means recheck, not safe-to-write. Auth refresh updates the lease deadline without requesting a history scan.                                                                             | Static; watcher completion fixture passed.                                                                                                                                                                  |
| 5 Default branches        | Unknown process/identity/schema, ambiguous catalog and exceeded limits preserve data and expose failure/attention. ## Performance and lifecycle

| Resource / state          | Required behavior                                                                                                                                         | Evidence                                                                                                                                                                                                                                                                                                                                 |
| ------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Startup / verified owner  | One bounded initial recovery pass for an existing managed profile; no unrelated user-history ingestion.                                                   | Actual cold starts recovered the compatible handoff; primary Claude showed both test sessions exactly once after another normal quit/reopen.                                                                                                                                                                                             |
| Visible / hidden idle     | Filesystem push invalidations, no periodic transcript scan; there is no status section or frontend listener.                                              | After UI removal and the round trip, visible idle samples were 0.3%, 0.0%, 0.0% CPU; RSS 295–329 MB. No claude-history-exit thread remained after writer exit. The final rebuilt App was hidden for three samples: 0.1%, 0.1%, 0.0% CPU and 137–159 MB RSS; no history-exit waiter remained. This does not cover sustained I/O or sleep. |
| Active writer / streaming | Callbacks mark bounded dirty state; no parsing in callbacks, no repeated waiter per delta.                                                                | Static; end-to-end coordinator event-storm acceptance pending.                                                                                                                                                                                                                                                                           |
| Writer exit               | kqueue notification; completion published before wake; fresh snapshot before write.                                                                       | Actual macOS isolated watcher harness passed.                                                                                                                                                                                                                                                                                            |
| Cancellation              | Explicit wake, joined thread, watchers dropped off executor. One-second cancellation fallback performs no process scan.                                   | Watcher harness passed; normal App quit removed its process, and final idle sampling found no history-exit waiter; forced-shutdown and full resource-count checks remain pending.                                                                                                                                                        |
| Owner A→B→A / logout      | Revoke native writes and old resources; discard late frontend results.                                                                                    | Frontend sync resources removed; native owner authority and retirement regressions passed; interactive multi-account transitions remain untested.                                                                                                                                                                                        |
| Lease refresh / expiry    | Refresh changes deadline without scanning; expiry releases resources and requests one canonical refresh. | Profile apply / restore   | Revalidate manifest changes and stop invalid profiles; use the shared managed configuration APIs.                                                         | Static; native restore/reapply pending.                                                                                                                                                                                                                                                                                                  |
| New conversation          | Bounded catalog discovery plus journaled transcript/row publication.                                                                                      | Handoff fixtures reported; primary App visibility, primary continuation, reverse package continuation and final primary cold-reopen visibility all passed in the combined native build.                                                                                                                                                  |
| Interrupted write         | Recover only if binding and recorded hashes still agree; never blind rollback.                                                                            | Handoff fixtures reported; process-crash acceptance pending.                                                                                                                                                                                                                                                                             |
| Self-generated events     | One extra invalidation may occur; clean state converges. Journal/backup paths are outside history event filters.                                          | Static; native convergence/I/O sampling pending.                                                                                                                                                                                                                                                                                         |
| Frontend mount / unmount  | No frontend synchronization resources or IPC.                                                                                                             | Static; 19 App connections regressions passed.                                                                                                                                                                                                                                                                                           |
| Independent Dock launch   | Cannot fence a new official writer or force memory reload; retain explicit limitation.                                                                    | Static limitation; native scenario pending.                                                                                                                                                                                                                                                                                              |

Performance verdict: resource ownership and bounds have been reviewed, and isolated watcher/frontend lifecycle checks passed. **Full native performance acceptance remains pending**. The limited idle CPU sample above is not a complete CPU/memory/I/O or Desktop synchronization acceptance result.
