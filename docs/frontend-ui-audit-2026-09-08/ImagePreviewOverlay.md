Clipboard review: convert the displayed full-resolution image to PNG on demand. Supply a Blob promise to `ClipboardItem` and call `clipboard.write` before awaiting conversion to retain WebKit user activation. Success is reported only after the write resolves; unavailable images, conversion errors, and clipboard rejection report failure. Canvas backing storage is released after encoding. No background work, polling, or cache is added. Animated images copy as a still image; native clipboard and rendered light/dark verification remain runtime checks, not proven by mocked DOM tests.
