# CursorSessionSetup UI audit

Scope: `src/features/SessionSetup/components/CursorSessionSetup/index.tsx`, audited as the third occurrence of the embedded-browser chrome the #780 audit (Neonforge98) said the OAuth shell should sweep ("`CursorSessionSetup/index.tsx:140-155` has the same showBrowser/100ms timer/closeSignal lifecycle"). Verdict: the chrome matches, the lifecycle does not, so Cursor stays on its own component. No source change in this PR.
