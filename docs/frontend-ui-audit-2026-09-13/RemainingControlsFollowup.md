## Verification and risk

Source/AST inventory, TypeScript, changed-file ESLint, and rendered tests verify shared-control adoption and event/selection behavior. The full-suite result is recorded in the PR after the final run. The circular-dependency check reports the same three pre-existing cycles in unchanged files. No persistence, dependency, IPC, or wire-format changes are needed; revert the follow-up commit to roll back.

Desktop visual QA was not performed because computer control is explicit opt-in. Shared wrappers and native Select replacement can affect sizing, focus appearance, popup positioning, and platform rendering; review these across themes and constrained widths. Native keyboard activation is provided by HTML buttons; jsdom assertions verify the native element, focusability, and click behavior rather than pretending that dispatching a synthetic keydown reproduces browser default activation.
