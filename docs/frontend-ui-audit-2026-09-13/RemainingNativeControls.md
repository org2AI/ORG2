# Remaining native inputs and buttons UI audit

Follow-up status: see [RemainingControlsFollowup.md](RemainingControlsFollowup.md) for the completed migration and reviewed exceptions. This report preserves the original inventory.

Scope: current production TypeScript/TSX working tree under `src`, after the 444-site JSX button migration. AST inspection excludes tests, fixtures, comments, and displayed code strings. Includes literal native-element creation in `.ts` files; dynamic tag aliases and every click handler were not exhaustively audited. Source-only audit; no application code changed.

## Summary

- 30 native JSX inputs, 7 textareas, and 1 select (38 total); these include reusable control implementations and browser-native controls.
- One native JSX button, inside the shared Button implementation.
- One additional React button bypass: branch deletion uses `createElement("button", ...)` in a `.ts` file. This was outside the earlier JSX-only inventory, not a newly established regression.
- 15 literal button-role sites: 10 divs, 4 spans, and 1 BasePill. These are separate from native button totals.
- Two deliberate non-React button boundaries: CodeMirror DOM creation and bootstrap fallback HTML.

## D2 / D3 — Presentation

Ordinary fields duplicate border, padding, height, typography, and focus styles. Match shared Input/Textarea sizes and caller-owned geometry rather than mechanically replacing tags. No global token or color audit was performed.

## D4 — Accessibility

The MarkdownLocalImage file chip needs keyboard activation. PinActionsPanel contains an insert span with `tabIndex={-1}` inside a Button: changing it directly to Button would create nested native buttons. Review parent/action structure together. Other literal role sites are inventoried as watch items, not asserted to be inaccessible solely because of their tag.

## D5 — Repeated structure

The search text-control extraction spans SearchInput (input + textarea), ReplaceInput (input + textarea), and SearchFilters (two inputs). Existing search-control styling helpers establish a shared presentation contract; a reusable control could also own common DOM props and resize behavior.

## Recommended order

1. Fix the missed branch-delete React button and keyboard-only file-chip gap.
2. Migrate the 11 ordinary field/editor sites as one sweep.
3. Extract the six-site search text-control layer.
4. Review six specialized fields and the remaining 14 button-role sites before deciding their implementation.
