# My Station chrome UI audit

Scope: the 36px bars and sidebars of My Station, plus the Agent Station replay chrome that reuses them. That means tab bars, header strips, file, page and detail bars, the status bar, sidebar shells, section headers, and the icon buttons inside them. Read-only pass on develop `7197f36d4a`; no source changes. IDs refer to `docs/architecture-audit-2026-09-14/MyStation.md`, which also covers structure, state and the PR order. Follow-up PRs: #1838 (BAR-1, BAR-5) and #1841 (dead code); verdicts stay as audited, and the Suggested change column records what they applied.
