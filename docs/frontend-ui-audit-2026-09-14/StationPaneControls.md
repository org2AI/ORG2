## Architecture review

Layer 8: not applicable—no IPC, serialization or persistence format changes. Layer 9: compared all three header entry points; each uses the same selector outside maximized-chat mode. Layer 10: both station headers now read stationChatVisibilityAtom directly, matching the pinned header's visibility source, instead of invoking a deferred atom getter during render. No multi-field persistence resolver changed.
