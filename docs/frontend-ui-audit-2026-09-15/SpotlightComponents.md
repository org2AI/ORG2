## Shared primitive scope

Form.Item's compact presentation is opt-in; its existing default layout and colon behavior remain. It now forwards native div attributes for anchors such as the organization-name tutorial target. No new Form wrapper is introduced. DropdownItem remains outside this sweep because its current clickable-div implementation cannot satisfy the shared Button convention; PickerOptionRow composes existing dropdown tokens and Button instead.

The shell centralizes panel fitting and themed surface only. Each picker retains its engine, search, grouping, list or submenu composition. No new positioning listener, observer, timer or cache owner is added. Model side-menu placement uses the main panel's actual capped width.
