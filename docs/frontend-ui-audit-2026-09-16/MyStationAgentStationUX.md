states, feedback on actions, keyboard reachability, ARIA semantics, and strings
that bypass `t()`. Read-only pass on develop `224b6a4d5b`; no source changed, no
app run, no screenshots. Structural, state-ownership and performance findings

`docs/architecture-audit-2026-09-16/MyStationAgentStation.md`; IDs there are
referenced where a UX symptom shares a root cause.

## Sweep candidates

Each is one decision, counted once above.

- **Hardcoded English in otherwise-translated files** — 36 `aria-label`/`title`/`placeholder`/`alt` literals plus ~8 label/tooltip props across 8 files. Worst concentration: `DesignPanel/index.tsx` (19 in one file). Note this is _not_ catalog drift: `check:i18n-keys` reports `missing 0, localeGaps 0, placeholderMismatches 0`. The strings simply never enter the catalog.
- **Icon-only buttons with no accessible name** — 37 sites. Fix the `Button` primitive with a dev warning rather than 37 call sites.
- **Role-less `onClick` on `div`/`span`/`li`** — 19 sites, 9 of them in the JSON and DOM tree views.
- **Hand-rolled menu surfaces bypassing `ActionMenuSurface`** — 3 sites, each losing Escape, focus return and roving focus.
- **Incomplete tablist patterns** — 3 containers, 6 files emitting `aria-selected`; only `WorkstationTrailTerminalHeader` implements the full pattern.
