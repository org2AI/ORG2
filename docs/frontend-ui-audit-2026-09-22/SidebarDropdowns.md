## Architecture scope

Reviewed compilation, structural reuse, naming, option semantics, default branches, shared-component boundaries, developer readability, and parity between right-click and overflow entry points (layers 1–7 and 9). OS allocation has been removed from all eight sidebar entry points. Existing `NativeMenuItemOptions` and builder names describe the retained input shape; they do not imply OS rendering. Layers 8 (wire serialization) and 10 (multi-field data resolution) are not changed. No persistence, backend, or shared global dropdown configuration changes.
