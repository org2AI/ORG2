# Sign-out illustration

The current asset is `src/assets/illustrations/sign-out.png`, generated with the
built-in imagegen tool as part of the diverse monochrome cast. The final shared
prompt and sign-out scene prompt are recorded in [monochrome-series.md](monochrome-series.md).

The logout character is designed as an Arab woman with medium grayscale skin
and wavy hair tied back, waving beside a laptop and mug. The shared Illustration
component preserves natural skin-tone relationships and dark facial features in
both themes without inversion. Generated transparency is preserved, and contain
fitting keeps the scene visible within the modal frame.
