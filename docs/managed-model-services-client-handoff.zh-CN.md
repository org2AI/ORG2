## 已提交的客户端链路

- 从公开 #1846 的固定 head `d6643ab39059a7cc89f3381529c7562f57c65c63` 选择迁入原生授权、OS 凭据存储、动态认证、会话代理、执行 profile、配置备份/冲突/恢复和相应历史路径依赖，没有整体合并旧分支。引用的测试与 fixture 也随相关调用链保留，但本次未运行。
- `src-tauri/crates/market-connect/src/services.rs` 读取带 `schema_version: 1` 的目录、确认用量授权并按 access/model/session 获取短时认证。目录分页每页 50、总数上限 100，响应字节有限制；未知协议、无效标识和越界响应拒绝接入。
- `workspace.rs` 将托管目录投影到现有 selector 合同；新增 `managed` 为可选字段，旧工作区 wire 路径仍可解析。已保存旧来源引用保留严格校验，不把缺失授权自动改成个人账号。
- `source.rs` 把授权连接、稳定 access、所选模型和会话标识放入无秘密来源引用，贯穿 Tauri → 正常会话创建/继续 → 持久化 → 重新打开。本地代理按需获得 bearer；renderer、IPC、配置文件只得到来源引用或本地代理凭据。
- 首次连接可从 Console 发起无需已有工作区的 ORG2 授权。新流程使用明确的初始连接 marker，原工作区链接仍按既有字段校验；不能用旧客户端启动了 URL 作为已兼容新目录的证据。
- 模型选择器使用动态目录。首次使用 Package 或服务端要求重新确认时，`UsageAuthorizationHost` 展示包内全部模型、公开价格区间及直接使用钱包的确认文案；一次确认启用全部模型，切换模型无需另行启用。钱包余额不足、授权失效等由服务器裁决，客户端不推算业务规则。
- `AppConnectionPage` 为每个 App 独立选择服务和模型。删除了聊天模型选择时自动重配/恢复其他 App 的逻辑；用户对一个 App 的操作只作用于该 App。
- 原生配置继续使用已有 hash 冲突保护、备份与恢复。Claude Code 打开终端，Claude Desktop/Codex 走对应的原生启动入口；ORG2 必须运行才能为动态来源提供本地代理。部分启动入口有平台限制，不能据此声明跨平台支持。
- Market 专用 MCP 注入/路由未迁入，正常用户 MCP/Skill 仍走本地执行链。
- 目录缓存 30 秒、连接变化失效、并发读取合并，过期请求不能覆盖更新后的读取。原生连接缓存最多 32 个 owner，每个 owner 最多 32 个短时认证，按过期时间淘汰；已结束会话不会永久消耗来源选择名额。运行中的 session route 另有独立拥有权与释放路径。

## 公开协议与兼容范围

| 调用 | 客户端读取/提交 |
| --- | --- |
| `GET /v1/market/packages` | schema、服务 ID/名称/版本、模型 ID/协议/兼容客户端、公开价格区间、模型价格区间、钱包计费能力、公开可用状态、现有 access、服务级 `requires_confirmation` |
| `POST /v1/market/package-access` | 服务、预期版本/revision、`billing_mode: wallet`、整包明确确认；不提交 model，返回无秘密 access |
| `POST /v1/market/package-access/:id/token` | 精确模型与会话；原生模块校验返回的 access、workspace、模型、session、有效期和 gateway origin |
| Tauri `market_connection_activate_service` | renderer 发起明确授权操作；原生层读取当前授权连接并代理公开 API |
| Tauri prepare/configure | 返回不含 bearer 的来源引用，分别用于单会话和单 App 的配置 |

新来源保持 `market:` 引用格式，含经过严格校验的选择信息；新增 model/session 字段仅对新 access 必填。服务器目录和短时授权响应显式检查版本。公开客户端不内置商品列表或服务器端价格计算策略。

兼容范围按服务器公开能力决定。首轮验收覆盖现有 Messages 与 Responses 执行器的文本、客户端工具和流式请求；服务端历史对象、多模态、其他协议或原生应用特殊请求不应推断为已支持。

## 整包授权修正与待测项

本次修正将授权状态移至服务级 `requires_confirmation`，Rust/TypeScript 与使用入口同步消费；启用 IPC/API 不再含 model。模型依旧用于会话路由及每个 App 的实际调用配置。暂时不可用或目标 App 不兼容的模型不因此变成单独购买项。

确认窗口展示所有包内模型并确认直接使用钱包，不能勾选模型子集。服务端要求重新确认时仍为整包操作。新的托管目录必须提供服务级字段；缺失时拒绝解析，不猜测授权状态，发布需与公开服务合同协调。旧非托管来源解析不变。

新增 `src/features/MarketConnect/usageAuthorization.test.ts` 覆盖一次确认后切模型、取消整包确认、单个模型暂时不可用。后续运行 `pnpm test -- src/features/MarketConnect/usageAuthorization.test.ts` 并做真实 UI/原生回归；本次未运行测试、类型检查、构建或 Computer Use，先前验收不能替代这次验证。App connections 的 review 修复已纳入后续提交：模型 Select 按共享回调类型转换为字符串；测试保留 Jotai 原始导出，并明确检查选择服务后尚未配置、点击连接后传入所选模型。套餐授权仍涵盖全部模型；这里的模型只用于目标 App 调用。本次只做源码审查和 diff 检查，未运行该测试或构建。

## 公开价格区间展示

目录新增可选的 `price_range_bps: { min, max }`，模型新增可选 `pricing_range: { min, max }`。确认窗口只展示公开区间和区间模型报价，不展示一个固定使用比例。Rust 与 TypeScript 同步解析；旧目录仍能读取，缺少公开区间时禁止新授权并提示刷新。

授权覆盖包内全部模型，直接使用钱包余额；区间内价格可变化，公开价格上限提高或增加模型时需重新确认。兼容字段 `pricing` 表达已发布区间的上限，新增界面不拿它冒充某个固定成交价。此仓库仅消费公开字段，没有增加服务端价格计算或运营配置。

本轮只做源码检查与格式化，没有运行测试、类型检查、构建或 GUI 验收。后续需验证区间展示、不带 model 的整包授权、区间内变化不重复确认、上限提高需确认，以及旧目录缺少区间时的提示。

## 钱包直扣与直接唤起

新启用请求使用 `billing_mode: wallet`，不再发送套餐预算。Rust access 的 `budget_usd6` 改为可空：wallet 必须为空，历史有限额模式仍接受正整数。目录读取显式声明 `wallet_billing=1`，根据 `billing_modes` 投影 `wallet_billing_supported`；旧服务器没有能力声明时界面禁止新启用并提示服务尚未更新，不自行假设支持。

已启用且无需重新确认的 wallet access 可以直接使用；历史有限额 access 需一次明确确认才能切换为钱包模式。所有包内模型仍共用同一个 access，多套餐共用钱包，后续充值无需重新调整套餐额度。确认按钮本身即授权，不增加预算输入和额外复选框。

市场完成套餐多选后直接唤起 ORG2；深链携带真实 access workspace，使既有连接可通过实时目录校验后复用。首次未授权时仍走原 PKCE 登录。需要用本分支实际构建验收浏览器唤起、连接复用、启用后首次调用与跨模型/跨套餐使用；本轮未运行这些验收，也没有修改本机原生配置。

回退时保留用户数据和 App 配置备份。旧客户端不能解析 wallet access 的空预算，必须依赖服务端在能力边界的隔离；不能把新版网页/API 的结果当作旧桌面版本兼容证据。
