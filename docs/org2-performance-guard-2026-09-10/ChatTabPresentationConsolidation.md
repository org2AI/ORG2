Lifecycle matrix: visible/hidden/idle states add no recurring work; active-tab changes synchronously recompute effective layout. Closing/unmounting consumers releases normal Jotai subscriptions. Test explicitly unsubscribes. State is isolated per store; no network, provider-ingestion, account/endpoint or secondary-process resource ownership changes. Existing DnD listeners and terminal subscription remain unchanged.

Performance verdict: blocked for real-app measurement only. CPU/RSS and visible/hidden/post-close runtime measurements were not run because desktop control was not authorized. Structural resource checks and unit tests pass; no measured speed or memory improvement is claimed. This limitation does not prevent review of the behavior-preserving refactor.
