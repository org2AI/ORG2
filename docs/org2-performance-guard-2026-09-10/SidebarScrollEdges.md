# Sidebar scroll edges lifecycle review

| Area               | Verdict | Evidence                                                                                           | Change or reason kept                                                                                                           | Verification                                                         |
| ------------------ | ------- | -------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------- |
| Background work    | keep    | SidebarList owns one passive scroll listener and one ResizeObserver observing viewport and content | Event driven, no timers, frames, polling, network, or mutation subtree scans; both resources disposed when loading or unmounted | SidebarList tests cover repeated loading and cleanup                 |
| Memory             | keep    | Fixed references to the mounted viewport and its content                                           | No growing collection or global cache                                                                                           | Observer disconnect and external ref clearing asserted               |
| Scope/isolation    | keep    | Resources local to each mounted SidebarList                                                        | No account, session, network, or cross-instance state                                                                           | Separate loading mounts create and dispose separate observers        |
| Rendering/hot path | keep    | Reads scroll geometry and writes two dataset flags only when edge states change                    | No React state updates or row rerenders from the scroll handler; shared CSS alpha mask                                          | DOM tests cover no overflow, top, middle, bottom, and content shrink |

React guidance applied: local ownership, passive listener, bounded DOM-only updates, symmetric cleanup. Existing useScrollFade was inspected; retained unchanged because it uses React state and does not observe the inner content's size. This sidebar requires resize-driven edge updates and loading-cycle attachment without rerendering its rows.

Lifecycle: initial loading owns no observers; ready mount checks once; idle has no scheduled work; active scrolling updates edge flags; resizing/content changes invalidate through ResizeObserver; loading/unmount dispose. Hidden surfaces have no recurring work; resize observation handles restored dimensions. Network, identity, provider ingestion, and transport matrices are not applicable.

Performance verdict: blocked for real Tauri visible/hidden idle and scroll profiling, which requires computer control that the user has not authorized. Automated lifecycle verification is covered; no measured CPU, memory, or frame-time improvement is claimed.
