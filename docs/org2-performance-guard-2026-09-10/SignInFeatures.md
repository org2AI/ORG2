# Login feature rotation

| Area               | Verdict | Evidence                                                                     | Change or reason kept                                                                               | Verification                                                                                                            |
| ------------------ | ------- | ---------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| Background work    | keep    | SignInFeatures owns one recursive timeout at six seconds                     | No timer while hidden, reduced-motion, or unmounted; visibility/motion listeners removed on cleanup | Fake-timer tests cover rotation, hidden/return, uninterrupted autoplay during hover, motion changes, unmount and reopen |
| Memory             | keep    | Three static bundled asset references, and one slide index                   | Fixed-size data; no cache, requests, or global state                                                | Fixed source inventory and timer count assertions                                                                       |
| Scope/isolation    | keep    | Feature showcase is presentation-only and local to each mounted login dialog | No account data or network access; auth actions retain their existing boundary                      | Settings/sidebar login and cancel tests                                                                                 |
| Rendering/hot path | keep    | Only the child showcase rerenders on the six-second timer                    | Modal and auth parents do not subscribe to slide index; no per-frame transitions                    | Component ownership inspection and rendered tests                                                                       |

Lifecycle matrix: visible rotation has one timer; hidden and reduced motion have none. Visibility return schedules one full interval. Closing/unmount clears the timeout and listeners; reopening starts on the first slide. Network, identities, provider sessions, synchronization and multiple-machine data boundaries are not touched.

Performance verdict: blocked for native CPU/RSS measurement across visible, hidden and closed states because desktop control was not authorized. Automated lifecycle invariants pass; no measured runtime performance claim is made.
