# Journey conflict integration performance guard

| Area               | Verdict | Evidence                                                                                                                                                | Change or reason kept                                                                  | Verification                                                  |
| ------------------ | ------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------- | ------------------------------------------------------------- |
| Background work    | keep    | Journey review owns a five-second recursive timeout only while a review panel is waiting; hidden documents clear it and unmount removes listener/timer. | Keep existing single-flight and generation guards.                                     | Journey controls DOM contracts; native idle CPU not measured. |
| Memory             | keep    | Exact-target navigation schedules one cancellable animation frame; target lookup uses existing paginated projection.                                    | Preserve cleanup, no new cache or polling owner.                                       | Exact-target and history projection suites.                   |
| Scope/isolation    | keep    | Snapshot reload generations reject stale session completions; sidebar actions use current context-menu owner.                                           | Move project-link callback into extracted row-actions hook.                            | Snapshot stale-completion and sidebar suites.                 |
| Rendering/hot path | keep    | Latest durable user ID remains a selectAtom over the keyed session events; current live-region conversation provider remains authoritative.             | Preserve narrowed subscription and runner bindings; no performance optimization claim. | Typecheck and chat/history tests.                             |

| Provider                    | Raw transition        | App/UI state | Topology/boundary | Expected invariant                                                                | Observed evidence                                                                         |
| --------------------------- | --------------------- | ------------ | ----------------- | --------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| Imported canonical sessions | Existing writer input | Unit fixture | Local ingest      | New canonical records receive default Journey metadata under current cache writer | orgtrack_core tests; native provider append/compact/rotate and cross-machine sync not run |

Lifecycle coverage: source inspection and automated contracts for visible/hidden polling, session switch, unmount, stale completion, exact target changes and pagination. Native start/idle/active/shutdown, offline retry, auth/endpoint switch, revocation and secondary-instance resource measurements were not run. No provider-ingestion or cloud-topology compatibility claim is made by this integration.

Performance verdict: blocked — no authorized desktop UI control or native CPU/RSS/hidden-window and multi-instance measurements. Existing pre-release measurement gaps remain; the separate unwired Journey production helpers are recorded in the architecture audit.
