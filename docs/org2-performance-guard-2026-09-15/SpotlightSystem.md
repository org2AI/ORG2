## Lifecycle matrix and limits

| Resource               | Start / active                 | Inactive / close                                  | Reopen / scope change          | Evidence                                                                        |
| ---------------------- | ------------------------------ | ------------------------------------------------- | ------------------------------ | ------------------------------------------------------------------------------- |
| Root selector listener | Root should be sole owner      | Child layer must disable root                     | Restore root selection once    | Static gating defect; shared selector listener-release test passes in isolation |
| Focus timers           | Schedule bounded focus         | Cancel pending callbacks                          | New open owns new callbacks    | Missing cleanup in source; rapid transition test needed                         |
| GitHub branch request  | Open, valid connection/repo    | Ignore obsolete view completion                   | A response must not replace B  | Missing guard in source                                                         |
| Worktree enumeration   | Single-flight equivalent reads | Cache may complete for its still-valid generation | Mutation forces new generation | Deferred-response probe reproduced stale refresh reuse                          |
| Cache and list         | Bounded cache, virtual list    | Root unmount disposes subscriptions               | TTL revalidation on demand     | Source plus existing tests                                                      |

Hidden-document CPU/RSS, account/endpoint switching in a real app, native focus behavior, network retry behavior, and multi-instance topology were not exercised. No new polling is proposed. Provider transcript ingestion and cloud transport are outside this audit's scope. Full fast typechecking is blocked by existing ChatHistory `hasBody` diagnostics, recorded in the architecture report.

**Performance verdict: fail** — active-listener ownership and stale-result paths remain in the current code. This is a source-level lifecycle verdict supported by one cache-race reproduction, not a measured CPU/RAM regression.
