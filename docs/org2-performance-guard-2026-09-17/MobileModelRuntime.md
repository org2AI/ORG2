# Mobile model selector resource ownership

| Area               | Verdict | Evidence                                                                                                             | Change or reason kept                                                           | Verification                                                                                                               |
| ------------------ | ------- | -------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| Background work    | fix     | Old mobile composition mounted local lookup and effort hooks, each subscribing to the shared credential store        | Desktop adapter owns desktop hooks; mobile supplies remote data to the view     | Call-through spies observe zero subscriptions/list/save across all eight mounted mobile tests                              |
| Memory             | keep    | New view owns the same refs/booleans and menu state as before; no cache, timer, worker, or retained catalog is added | Component-local lifetime unchanged                                              | Three unmount/remount cycles; desktop suite verifies overlay count and timers return to zero                               |
| Scope/isolation    | fix     | Remote config and catalog identify current session/account                                                           | No desktop key-store consumer can apply local defaults or persist mobile effort | New account/session effort selection emits the new remote account; local-store publication creates no desktop subscription |
| Rendering/hot path | keep    | Label and effort derivation remain memoized and driven by supplied props                                             | No polling or broader subscription is introduced                                | Existing model-label/menu suite and remote effort suite pass                                                               |

The zero-desktop-resource invariant holds for cold mount, idle, open menu, loading/failed catalog, session/account replacement, and unmount/remount in jsdom. Visibility/network events cannot activate a removed desktop hook. Remote transport, provider ingestion, and desktop credential lifecycle are unchanged; they are not claimed as revalidated here.

Performance verdict: **blocked for native runtime measurements**. Resource isolation is evidenced by mounted regression tests, including a negative run of the old composition. Native iOS CPU/RSS, hidden-app behavior, and real desktop credential persistence were not measured; no quantitative performance improvement is claimed.
