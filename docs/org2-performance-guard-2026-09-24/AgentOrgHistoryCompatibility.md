## 实机资源样本及其限制

初版隔离包每种状态取 6 个主进程样本、窗口约 25 秒：

| 状态         | 主进程平均 CPU（累计 CPU 时间差） | 主进程 RSS KiB  | 历史事件 / 模型用量记录 |
| ------------ | --------------------------------- | --------------- | ----------------------- |
| 历史可见     | 4.55%                             | 237,728–237,776 | 947 / 720，不变         |
| 应用隐藏     | 0.00%                             | 238,224–238,272 | 947 / 720，不变         |
| 历史标签关闭 | 0.36%                             | 239,552–239,600 | 947 / 720，不变         |

这些是主进程局部样本，不是 WebView 总内存、长期稳定性或原版本性能对比。可见状态仍复用既有正文/Agent Station 渲染，不能将其 CPU 视为迁移成本。

随后发现 Agent Station 共享运行视图收到历史只读错误时仍保留 60 秒 fallback，已在共享 store 修正；自动测试证明多个消费者和重连不继续发现，当前团队仍可轮询。初版 25 秒窗口无法证明原 60 秒 fallback 不存在，不把初版样本误当作修正通过证据。最终安装包已使用新的隔离旧库重复浏览，跨过 60 秒周期；Command+5 没有历史运行视图持续请求，只有原有侧栏刷新和按需正文读取。最终量化样本见下表。

每种状态 16 个样本，约 75 秒，覆盖原运行视图 60 秒重试周期；“离开历史”是切换到空白新会话而保留旧标签，“关闭历史”才是明确关闭该标签。历史原事件始终 947，模型用量记录始终 720。原始样本与汇总分别保存为 `final-lifecycle-samples.jsonl`、`final-lifecycle-summary.json`。反复打开、成员切换和保存内容下一页均通过；归档根可置顶；真实重启数量对照见最终验收记录。

样本只包含测试主进程，不能代替 WebView/子进程总资源、长期内存稳定性或旧版性能对照。现有侧栏每约 15 秒刷新属于原行为；本次未扩展到该轮询的全仓治理，也不声称零后台请求。

Performance verdict: pass with evidence boundary — 历史浏览生命周期的自动检查和最终包短窗口实测已完成；用户于 2026-09-25 报告“新团队真实模型增量写入/恢复”和“官方 v2.0.8 降级/再升级”两格验收成功。代理没有代为执行模型请求，且未收到逐项资源样本，因此该签收只关闭人工验收门槛，不扩展为长期内存、整机资源或旧版性能对照结论。
