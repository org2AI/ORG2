This review covers resources affected by whole-Workstation floating presentation. Unit evidence establishes lifecycle wiring and bounded scheduling. No native CPU/RSS/process measurements have been collected by this review.

## Verification

The visibility implementation passed 7 test files / 33 tests ; the additional drag/drop run passed 2 files / 4 tests. Targeted ESLint passed for the changed visibility/geometry/Project paths, and their diff whitespace check was clean. Integrated typecheck passed with no diagnostics. Root integration runs passed 31 distinct files / 168 tests; worker final layout-state rerun passed 52 tests. The current development page passed float/drag/resize/collapse/reopen/dock browser smoke and narrow-viewport boundary fitting. These checks do not substitute for real Tauri measurements. See the architecture report for exact scope and limitations.

Performance verdict: blocked — required native visible-idle, hidden-idle, active drag, repeated collapse/restore and multiwindow resource measurements remain unexecuted. The source and unit evidence does not establish a runtime performance improvement or native browser layering correctness.
