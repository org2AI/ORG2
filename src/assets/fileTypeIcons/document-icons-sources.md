# Document icon sources

Numbers and Pages use document glyphs from [Pictogrammers Material Design Icons](https://github.com/Templarian/MaterialDesign), matching the existing 24×24 filled document style. These are file-type illustrations, not official Apple app logos.

| Local asset | Upstream SVG                                                                        | Modification        |
| ----------- | ----------------------------------------------------------------------------------- | ------------------- |
| numbers.svg | https://github.com/Templarian/MaterialDesign/blob/master/svg/file-chart.svg         | Green fill #43A047  |
| pages.svg   | https://github.com/Templarian/MaterialDesign/blob/master/svg/file-document-edit.svg | Orange fill #FB8C00 |

Retrieved 2026-09-07. Geometry is unchanged. Icons are distributed under Apache 2.0 per the [upstream license](https://github.com/Templarian/MaterialDesign/blob/master/LICENSE); license text is included in `LICENSE-material-document-icons.txt`.

The existing `excel.svg`, `word.svg`, and `powerpoint.svg` assets are reused unchanged.
